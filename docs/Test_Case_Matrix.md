## 一、主用例表

约定：

- 位串按 **b7…b0**（或 b3…b0、b15…b0）书写，**最左边是符号位**；
- `C_n` 指符号位向外的进位，`C_(n-1)` 指最高数值位向符号位的进位；
- `V = C_n ⊕ C_(n-1)`；
- 减法行的 `[Y]补` 列填写的是 **`[−Y]补`**（即实际参与加法的操作数）。

## 二、随机对拍（属性测试）

```python
import random
from src.core.engine import build_scenario

def test_random_200():
    for _ in range(200):
        width = random.choice((4, 8, 16))
        lo, hi = -(1 << (width - 1)), (1 << (width - 1)) - 1
        x, y = random.randint(lo, hi), random.randint(lo, hi)
        op = random.choice("+-")
        sc = build_scenario(x, y, op, width)

        # 数学结果恒定正确
        expect = x + y if op == "+" else x - y
        assert sc.math_value == expect

        # 机器结果 = 数学结果 mod 2^n，按补码解释
        raw = expect % (1 << width)
        assert sc.machine_value == (raw - (1 << width) if raw >= (1 << (width - 1)) else raw)

        # 溢出 ⇔ 数学结果超出区间
        assert sc.overflow.overflowed == (not (lo <= expect <= hi))

        # 三种判定方法结论一致
        assert sc.overflow.consistent
```

**对拍的意义**：AI 写的位运算很容易在"符号扩展""边界加减"上出错，而这类错误用固定用例很难覆盖全。用 Python 原生整数做参照系，200 组随机输入能在几秒内暴露绝大多数偏差。
